# LangCell: Language-Augmented Single-Cell Foundation Model

## Quick Summary

LangCell is a cell-centric transformer encoder that incorporates natural language information (cell type descriptions, biological annotations) to enhance single-cell representations. Benchmarked as a key baseline in comprehensive foundation model comparisons.

## Key Points

- **Language Integration**: Combines gene expression with textual descriptions
- **Cell-centric Architecture**: Focuses on individual cell encoding
- Improved generalization through language grounding
- Competitive in few-shot learning tasks

## Applications

- Cell type annotation with explanations
- Transfer learning leveraging language context
- Few-shot cell classification
