# CELLama: LLM-Based Single-Cell Analysis

## Quick Summary

CELLama is an LLM-adapted single-cell foundation model that leverages large language model architectures for cell analysis. It demonstrates the potential of adapting general-purpose language models to single-cell genomics without specialized bioinformatics architectures.

## Key Points

- **LLM Architecture**: Applies standard transformer LLM design to cells
- **Natural Language Interface**: Query cells using natural language
- **Unified Modality**: Treats gene expression as sequential tokens
- Benchmarked in comprehensive foundation model evaluations

## Performance

- Competitive with specialized models
- Strong natural language reasoning capabilities
- Efficient inference with standard LLM optimizations

## Applications

- Natural language queries on cell data
- Interactive cell exploration
- Foundation model baseline
