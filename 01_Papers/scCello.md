# scCello: Single-Cell Embedding with Contrastive Learning

## Quick Summary

scCello is a single-cell foundation model that uses contrastive learning to learn cell representations. It leverages the cell-centric approach to encode individual cells and has been benchmarked as a key baseline in comprehensive foundation model comparisons.

## Key Points

- **Cell-centric Transformer encoder** architecture
- **Contrastive learning** objective for robust embeddings
- Strong baseline in zero-shot and few-shot tasks
- Identified as having implementation bugs in benchmarking studies (fixed)

## Applications

- Cell type annotation
- Embedding extraction for downstream tasks
- Transfer learning to new datasets
- Few-shot learning scenarios

## Performance

- Competitive in zero-shot clustering
- Good few-shot learning capabilities
- Scalable to large datasets
