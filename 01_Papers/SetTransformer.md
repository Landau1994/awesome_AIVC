# Set Transformer

## Quick Summary
> **Set Transformer** introduces attention-based architectures for processing set-structured data. It proposes Induced Set Attention Blocks (ISAB) that reduce the quadratic complexity of self-attention to linear, enabling scalable permutation-invariant set processing.

## Key Points
- Multihead Attention Block (MAB) and Induced Set Attention Block (ISAB)
- Pooling by Multihead Attention (PMA) for set-level aggregation
- Inspires the MCAB architecture in [[arixv 2025 Scalable Single-Cell Gene Expression Generation with Latent Diffusion Models|scLDM]]
