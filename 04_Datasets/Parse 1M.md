# Parse 1M

## Overview
> A large-scale perturbation dataset (~1M cells) from Parse Biosciences, profiling cellular responses to cytokine perturbations. Used as a benchmark for conditional generation and perturbation prediction models.

## Usage
- Perturbational benchmark in [[arixv 2025 Scalable Single-Cell Gene Expression Generation with Latent Diffusion Models|scLDM]]
- Tests conditional generation with cytokine treatments
