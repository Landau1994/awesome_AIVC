# Tabula Sapiens 2.0

## Overview
> The second Tabula Sapiens release contains over 1.1 million cells from 28 organs/tissues and 24 donors. The roughly 500,000-cell figure describes the original release, not version 2.0.

## Usage
- Downstream classification evaluation in [[arixv 2025 Scalable Single-Cell Gene Expression Generation with Latent Diffusion Models|scLDM]]

## Sources and version scope

- [Consortium overview](https://tabula-sapiens.sf.czbiohub.org/about)
- [Version 2 data release](https://figshare.com/articles/dataset/Tabula_Sapiens_v2/27921984)
- scLDM evaluates a six-tissue subset, not all cells in the atlas. See [Appendix G and section 4.3](https://arxiv.org/html/2511.02986v1#S4.SS3).
