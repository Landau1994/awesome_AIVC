# Tabula Sapiens

Tabula Sapiens is a human multi-organ single-cell reference atlas. The original 2022 release and [[04_Datasets/Tabula Sapiens 2.0]] are different versions. Record the release, donors, tissues and filtering used by each benchmark; do not substitute the full atlas count for a test subset.

Sources: [original Science paper](https://doi.org/10.1126/science.abl4896), [consortium overview](https://tabula-sapiens.sf.czbiohub.org/about).
